# 🧪 Scripts de Prueba

Esta carpeta contiene scripts para probar y verificar el funcionamiento del sistema.

## 🔍 Scripts de Verificación
- `check_hidro_tables.py` - Verificar tablas en base hidro
- `check_activities_schema.py` - Verificar esquema de actividades
- `verify_data.py` - Verificar datos en base de datos

## 🔗 Scripts de Conexión
- `test_db.py` - Probar conexión general a BD
- `test_postgres_connection.py` - Probar conexión PostgreSQL
- `test_backend_connection.py` - Probar conexión al backend

## 🚀 Uso
```bash
# Verificar tablas
python tests/check_hidro_tables.py

# Probar conexión
python tests/test_postgres_connection.py
```
