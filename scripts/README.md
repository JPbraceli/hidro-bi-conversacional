# 📁 Scripts de Utilidad

Esta carpeta contiene todos los scripts de utilidad para el proyecto HidroChat.

## 🗄️ Scripts de Base de Datos
- `create_hidro_db.py` - Crear base de datos hidro
- `import_all_dumps.py` - Importar todos los dumps
- `setup_hidro_complete.py` - Setup completo de BD
- `restore_to_hidro.py` - Restaurar a base hidro
- `create_hidro_data.py` - Crear datos de prueba

## 🔍 Scripts de Verificación
- `check_hidro_tables.py` - Verificar tablas en hidro
- `check_activities_schema.py` - Verificar esquema de actividades
- `verify_data.py` - Verificar datos en BD

## 🧪 Scripts de Prueba
- `test_db.py` - Probar conexión a BD
- `test_postgres_connection.py` - Probar PostgreSQL
- `test_backend_connection.py` - Probar backend

## 📋 Scripts de Configuración
- `manual_setup.py` - Setup manual
- `quick_setup.py` - Setup rápido
